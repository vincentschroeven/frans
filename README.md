# Frans oefenen

Korte dagelijkse oefeningen Frans op weg naar niveau B1: voegwoorden, werkwoordstijden, voornaamwoorden (COD/COI), lidwoorden, woordenschat (Rappel, lijst 10–11) en luisteroefeningen.

- Eén bestand (`index.html`), geen installatie nodig.
- Voorlezen gebruikt de ingebouwde voorleesstem van je toestel.
- De vertalingen en voorbeeldzinnen zijn zelf geschreven en komen niet uit een lesboek.

Online via GitHub Pages: https://vincentschroeven.github.io/frans/
